# Post 3: Build your first agent

Stages 0 to 2 of the build: a tool with no AI, then the model meeting that tool in a loop.

- `demo/` is the messy practice folder. Copy it into your `my-first-agent` folder.
- `stages/stage1.py` is your `agent.py` at the end of stage 1: one tool, no AI, free to run.
- `stages/stage2.py` is your `agent.py` at the end of the post: the model, its standing instructions, one tool and the loop. About 25 lines of loop. That's the agent.

Each file's docstring says how to run it and what you should see. Compare with yours whenever a checkpoint doesn't match.
